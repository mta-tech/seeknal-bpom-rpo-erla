# Definisi — PerBPOM 10/2026 (Pasal 1)

Definisi kunci (ringkasan arti, bukan kutipan verbatim — kutip Pasal 1 saat menjawab formal):

| Istilah | Arti |
|---|---|
| ING (Informasi Nilai Gizi) | informasi kandungan zat gizi dan zat non-gizi pada Pangan Olahan yang dicantumkan pada Label |
| Takaran Saji | jumlah pangan Olahan yang dikonsumsi dalam satu kali penyajian/makan, menjadi dasar pencantuman ING |
| Pangan Olahan | pangan atau minuman yang dibuat/diolah dengan proses tertentu untuk konsumsi |
| PKMK | Pangan Olahan untuk Keperluan Medis Khusus — diformulasi untuk manajemen diet penyakit/gangguan tertentu |
| PKGK | Pangan Olahan untuk Keperluan Gizi Khusus — diformulasi untuk kebutuhan gizi tertentu karena kondisi fisik/fisiologis/penyakit |
| Pelaku Usaha | orang perseorangan atau korporasi yang memproduksi dan/atau mengedarkan Pangan Olahan |
| Kepala Badan | Kepala Badan Pengawas Obat dan Makanan |
| Nutri-Level | penandaan level A/B/C/D pada bagian depan kemasan minuman berdasarkan gula, garam (natrium), lemak total |
| Logo Pilihan Lebih Sehat | logo pada bagian depan kemasan untuk Pangan Olahan yang memenuhi profil gizi (Lampiran IV) |
